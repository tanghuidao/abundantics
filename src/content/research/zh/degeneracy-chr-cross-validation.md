## 摘要

本文报告在构建 TEPI（Token 能量平价指数）过程中得到的两项发现。TEPI 是一个日频指数，比较两种高耗能数字活动——比特币挖矿与大语言模型（LLM）推理——各自每千瓦时挣得的毛收入。第一项发现：若给一个异质商品做"质量调整"时，所用的质量权重本身来自该商品的价格，那么由此得到的"质量调整后平价偏离度"在代数上必然坍缩为未经调整的原始价格比值，与底层数据无关——它悄悄丢弃了自己本应做出的那个调整，却不会在形式上暴露出来。我们给出这一命题的一般性证明，并指出本指数早期版本的首个发布快照恰好呈现了这种坍缩。修复方法是：要求质量权重必须来自一个独立于价格的外部基准；我们用 2026 年 8 月的数据验证了修复后指数确实恢复了信息量。第二项发现：一个同期发表、方法上完全独立的项目——Compute Heat Rate（CHR），它从厂商直连定价与硬件基准出发，测算 AI 负载对电价的承受能力——其核心结果与 TEPI 的核心量在数量级上相互吻合，尽管两者没有使用任何相同的数据源。我们如实报告这两项发现，并明确说明它们各自能够、以及不能够证明什么。

## 1. 引言

从物理输入的角度看，比特币挖矿与 LLM 推理是同一件事：把电能转化为一个数字 token。在丰裕学研究纲领的解读框架里，二者的差异在于经济功能而非物理机制——挖矿是一种**防御性耗散**（为保卫既有权利主张而消耗能量，呼应 Baumol（1990）关于企业家才能在生产性与非生产性用途间配置的分析），推理则是**生产性耗散**（为产出认知性成果而消耗能量）。这是一种研究透镜，不是规范性裁决，指数本身的计算不依赖这一解读。

TEPI 回答一个狭窄而可测量的问题：按今天的市场价格，一度电在两种用途中各挣多少毛收入？经模型质量调整之后，缺口有多大？它不度量利润、福祉或能耗份额，也不构成投资建议。其构造遵循购买力平价（PPP）指数一贯的"物理公分母"逻辑（Balassa, 1964；Samuelson, 1964），最广为人知的通俗版本是《经济学人》的巨无霸指数，只是这里用焦耳而非单一零售商品作为共同货币。

本文报告构建 TEPI 过程中浮现的两件事，我们认为它们的意义超出这一具体指数本身。第 3 节陈述并证明一个退化命题：如果一个异质商品的质量调整权重本身来自该商品的价格，那么由此得到的"偏离质量调整后平价"的程度，在任意数据、任意日期下都必然等于未经调整的价格比值。我们并不确定价格指数文献中是否已有文献明确陈述过这个具体结果——它很可能是享乐价格法与质量调整方法论中某些已知担忧的一个特例；我们不主张优先权，只是我们尚未见过它被如此明确地陈述出来，而它确实让我们（在正式对外发布之前）报废过自己指数的一个内部版本。第 5 节报告一次独立交叉验证：一个方法论上毫不相关的项目——Compute Heat Rate（CHR；Royal, 2026）——在没有使用任何相同数据源的情况下，得出了与 TEPI 核心结果同一数量级的数字。

## 2. TEPI 简介

TEPI 每日发布四个量：

| 符号 | 名称 | 定义 |
|---|---|---|
| $R_M$ | 挖矿每度电毛收入 | 按全网加权能效计，一度电的挖矿毛收入 |
| $R_A$ | 推理每度电毛收入 | 按用量加权的模型篮子，一度电的推理毛收入 |
| $\Lambda$ | 能量套利比 | $R_A$ / $R_M$（以链式接续序列 $\Lambda_{\text{chained}}$ 发布） |
| $\Omega$ | 平价偏离指数 | 质量调整后、以能量计价的隐含汇率与市场隐含汇率之比的对数 |

挖矿侧：$R_M = \text{hashprice} / E_{\mathrm{PH}}$，其中 hashprice 是每 PH/s 每日的挖矿毛收入，$E_{\mathrm{PH}}$ 是在假定的全网加权挖矿能效 $\eta$（J/TH）下、一个 PH/s 每日的耗电量。化简后得到恒等式 $R_M = k \cdot P_{\mathrm{BTC}} / \varepsilon_{\mathrm{BTC}}$，其中 $P_{\mathrm{BTC}}$ 为比特币现货价格，$\varepsilon_{\mathrm{BTC}}$ 为边际一枚比特币内含的能量，$k = 3.6 \times 10^6$ J/kWh。

推理侧：对篮子中的每个模型 i，其输出 token 单价为 $p_i$（美元/token），每 token 全栈能耗为 $j_i$（J/token），用量权重为 $w_i$（$\sum_i w_i = 1$）：

$$
R_A = k \sum_i w_i \, \frac{p_i}{j_i}
$$

模型的原始 token 会用一个独立于价格的外部质量权重 $q_i = s_i / s_{\text{ref}}$ 折算为"标准 token"，其中 $s_i$ 是一个价格无关的能力评分（目前采用 Artificial Analysis Intelligence Index）。由此得到每模型每焦耳的标准 token 产出 $t_i = q_i / j_i$，篮子合计 $T = \sum_i w_i \, t_i$。

随后比较两个汇率：$\rho_{\text{parity}} = \varepsilon_{\mathrm{BTC}} \cdot T$（一枚比特币内含的能量，若改投质量调整后的推理，能产出多少标准 token）与 $\rho_{\text{market}}$（按市场价格，一枚比特币能买到多少标准 token）。$\Omega = \ln(\rho_{\text{parity}} / \rho_{\text{market}})$。

完整推导与数据来源见公开方法论（Tang, 2026）。

## 3. 退化命题

**命题**：若模型 i 的质量权重直接由其价格定义，即 $q_i = p_i / p_{\text{ref}}$（$p_{\text{ref}}$ 为某参考价格），则对任意篮子配置、任意权重 $w_i$、任意日期，恒有 $\Omega \equiv \ln \Lambda$。

**证明**：将 $q_i = p_i / p_{\text{ref}}$ 代入 $t_i = q_i / j_i$，得 $T = \sum_i w_i \, (p_i / p_{\text{ref}}) / j_i = (1/p_{\text{ref}}) \sum_i w_i \, p_i / j_i$。于是：


$$
\frac{\rho_{\text{parity}}}{\rho_{\text{market}}}
= \frac{\varepsilon_{\mathrm{BTC}} \cdot T \cdot p_{\text{ref}}}{P_{\mathrm{BTC}}}
= \frac{\varepsilon_{\mathrm{BTC}} \sum_i w_i \, p_i / j_i}{P_{\mathrm{BTC}}}
$$


而 $\Lambda = R_A/R_M = \bigl(k \sum_i w_i \, p_i / j_i\bigr) \big/ \bigl(k P_{\mathrm{BTC}} / \varepsilon_{\mathrm{BTC}}\bigr) = \varepsilon_{\mathrm{BTC}} \sum_i w_i \, p_i / j_i \big/ P_{\mathrm{BTC}}$——与上式完全相同。故 $\rho_{\text{parity}}/\rho_{\text{market}} \equiv \Lambda$，对任意配置、任意日期均有 $\Omega = \ln \Lambda$。∎

这一结果不是某组参数值下的近似或巧合，而是一个不依赖篮子、权重或日期的代数恒等式。任何指数只要（a）用价格构造一个"质量"调整，又（b）反过来检验价格是否偏离该质量调整后的基准，那么在不知情的情况下，它比较的其实是同一个量和它自己。看似独立的第二个信号（"质量调整后"的那个）除了第一个信号之外不携带任何额外信息。

**实证坐实**：TEPI 内部最早的版本（第 0 版）恰好采用了这一构造，$q_i = p_i / p_{\text{ref}}$。它首个发布的快照给出 $\Omega = 5.457 = \ln(234.4)$——在所报告的精度下与 ln $\Lambda$ 完全一致，正如命题所预言。这一点并非通过检视公式本身发现，而是通过两个"本应独立"的已发布数字之间的经验巧合被察觉的——这本身也是给其他实践者的一个有用的诊断信号：**如果一个价格比值的"质量调整后"配套序列，在每一个观测点上都与该比值的某个单调变换在数值上无法区分，那么这个质量调整很可能没有起到任何作用。**

我们不确定享乐价格指数文献中是否已有对这一具体退化形式的命名，尽管我们不会感到意外——享乐或质量权重不得由其本应调整的同一价格数据估计而来，这一更宽泛的告诫本身与该文献中一些标准担忧是一致的。我们不主张任何优先权，只是认为把它以这种明确、可证明的形式陈述出来，或许对其他构建跨市场或质量调整型指数的人有用，尤其是在那些不像官方 CPI 编制那样已有制度性防护措施来规避这一陷阱的场景中。

## 4. 修复方案及其后果

TEPI 当前版本（v0.1）要求 $q_i$ 必须来自一个独立于价格的基准——目前采用 Artificial Analysis Intelligence Index，一个不参照、也不使用 API 定价数据进行评分的第三方 LLM 评测。做出这一改动后，$\Omega$ 不再恒等于 ln $\Lambda$。以 2026-08-16 的验证运行数据为例：

| 量 | 数值 |
|---|---|
| $\Lambda$ (= $R_A / R_M$) | 233.93 |
| ln $\Lambda$ | 5.455 |
| $\Omega$ | 5.738 |
| 质量项（$\Omega - \ln \Lambda$） | 0.283 |
| 隐含质量溢价，$e^{\Omega - \ln \Lambda}$ | ≈ 1.33 |

质量项如今是真正有信息量的、且可与原始能量套利比分离的一个量：在这一天，篮子内四个模型按外部基准衡量几乎质量等价（归一化权重 0.96–1.02），价格却横跨 7.5 倍区间——这意味着市场为较贵模型支付的隐含溢价，超出了独立能力度量所能解释的部分。这是一个具体而重要的实证观察，而它之所以可见，恰恰是因为质量信号不再从定义上被绑死在它本应评估的那个价格上。

## 5. 通过 Compute Heat Rate（CHR）做的独立交叉验证

Compute Heat Rate（Royal, 2026）是一个独立开发的指数，与 TEPI 站在同一个概念交叉点——AI 负载的能量与价格之交——但方向相反，数据管线也完全独立。TEPI 问一度电在两种用途中各挣多少毛收入，CHR 问一个给定的 AI 工作负载档位，在扣除非电力成本与必需回报率之后，还能承受多高的电价：


$$
\mathrm{CHR}_w = \frac{R_w - C_{\text{non-elec}}}{1 + m}
$$


CHR 的输入是厂商直连 API 定价（Anthropic、OpenAI、Google）、GPU 规格与 MLPerf 推理基准，以及第三方数据中心设施成本报告——这些与 TEPI 的输入（OpenRouter 聚合定价，以及一个关于每 token 能耗的工作假设，篮子内为 1.0–3.0 J/token）没有任何重叠。CHR 已被 2026 年 PJM（美国最大电网运营商）一份关于需求响应市场设计的白皮书引用，说明它在独立于 TEPI 之外，已具备一定的政策层面影响力。

**发现一——每度电收入在数量级上吻合**。将 CHR 的混合参考值（2026 Q1）换算到与 TEPI 相同的单位，得 $R_w$ ≈ \$12.5/kWh，对比 TEPI 前沿篮子口径的 $R_A$ ≈ \$15.4/kWh——尽管定价来源完全独立，二者仍处于同一数量级。（这里对比的是 CHR 的毛收入 $R_w$，而不是它对外发布的净值"headline CHR"——后者已经扣除了非电力成本与必需回报率，概念上更接近 TEPI 未来的利润率变体 $\Lambda'$，而不是 $\Lambda$ 所依赖的那个毛收入量。）CHR 的走量档位数值（\$1.85/kWh）隐含的挖矿-推理比值约为 28 倍，与产业界常引用的走量模型 20–25 倍区间一致——这与 TEPI 自身前沿篮子口径下的 $\Lambda$（234 倍）并不矛盾，因为二者定价的是不同（层级不同）的篮子。这一点需要明确说明：**两个数字测的不是同一个篮子**，恰当的解读是两种方法各自在其篮子选择内部自洽，而不是彼此互相证明了对方的绝对水平。

**发现二——隐含每 token 能耗的独立收敛**。用 CHR 公开的各档位收入反推厂商 GPU 规格与 MLPerf 基准，得到前沿及中端推理的隐含每 token 能耗约为 1.1–2.8 J/token。TEPI 独立选定的工作假设区间是 1.0–3.0 J/token。这两个数字是通过互不相关的方法得到的（CHR：硬件基准与厂商直连定价；TEPI：一个待正式溯源附录支撑的工作假设），在 TEPI 最初设定这一假设时也未曾相互核对过。二者的收敛，在我们看来，是一条有意义的证据，可以驳斥（此前一份内部草稿曾认真考虑过的）"TEPI 的每 token 能耗假设被系统性低估约一个数量级"这一具体判断。

**关于 2026 Q3 更新的说明**。本文起草之后，CHR 发布了 2026 年第三季度参考值（2026-09-01）。我们选择在此明确标注，而不是悄悄替换成最新数字，原因有二。其一，Q3 发布的混合 CHR 降到约 \$5,630/MWh，比 Q2 低约 30%——但 CHR 官方发布本身把这一变化主要归因于一次全系统功耗分母的修正（从 Q1/Q2 仅计 GPU 本体的 7.28 kW，改为整机系统口径的 13.26 kW）以及负载分类与权重体系的重建，并明确提醒"环比变化不应被解读为纯粹的市场价格变动"。我们刻意没有用 Q3 数字重新计算本文的对比，因为不加甄别地这样做，恰恰会犯我们在第 7 节提醒他人避免的那个错误——把方法论修订和现象本身的变化混为一谈。其二，CHR 的 Q3 发布引入了一个新的调度侧配套指标 CHR-D，与用于新建/选址决策的长期 CHR 区分开来。这一区分与我们自己方法论中已声明的一条局限（L3：TEPI 的 $R_A$ 假设 100% 可计费利用率，因此是一个长期、上界性质的量，目前尚无调度侧的对应版本）正好呼应。我们把这看作两个互不相关的研究项目独立收敛到同一个结构性区分的又一例证，也进一步佐证了为 TEPI 开发一个利用率修正变体的必要性。另外值得肯定的是：CHR 并没有用新方法论悄悄改写 Q1/Q2 的已发布数字——这与 TEPI 自身"只记不回溯"的纪律是一致的。

我们希望明确说清楚这两项发现能证明什么、不能证明什么。它们是独立方法之间的数量级吻合，对于这一类几乎没有正式同行评审基础设施的指数而言，这是一种真实且相对稀缺的早期验证形式。但它们不能证明两种方法测的是同一个底层经济量——利用率假设、成本口径（毛收入 vs 净收入）、token 核算方式（输入 vs 输出）在两种方法之间存在差异，这些差异有可能造成表面上的巧合而非结构性的一致。我们把这作为一个数据点如实报告，而非一次"确认"。

## 6. 局限

TEPI 对自身的度量边界一贯保持明确声明，完整内容见公开方法论。简要而言：它比较的是毛收入而非利润（电力是挖矿的主导边际成本，却只占推理成本的次要份额）；仅计入输出 token，忽略输入 token 收入与 prefill 能耗；假设 100% 可计费利用率，使 $R_A$ 与 $\Lambda$ 均为上界；全网挖矿能效与每 token 能耗均为人工设定、季度复查的参数，其敏感性已被量化；推理侧目前主要依赖单一价格聚合商，2026 年 9 月起引入的第二个厂商直连价格源部分缓解了这一点。一个利润率版本（$\Lambda'$）正在开发中；用 2026 年二季度财报数据做的初步试算显示，现金成本口径下的 $\Lambda'$ 明显高于毛收入口径的 $\Lambda$，但在全成本口径下，挖矿侧与推理侧的利润率均为负——我们认为这一结果足够重要，值得在这一变体正式发布前单独撰文处理。

## 7. 讨论

给同样在快速演变的领域（AI 经济学、加密货币相关的测量工作）中构建类似的新颖、高频、跨市场指数的其他实践者，两点实用的经验：

第一，为异质商品构造质量或享乐调整时，务必用代数方式（而不只是目测公式）核实：该调整权重不能从它本应评估的那条价格序列反推出来。这个失效模式未必在公式本身就能看出来，它可能只会以两个"本应独立"的已发布数字之间的经验巧合的形式浮现——正如本文所述。

第二，在这一类正式同行评审相对于底层现象演进速度而言过于缓慢（或缺席）的领域，来自一个方法论上完全不相关的项目的独立交叉验证——哪怕对方本身也未经评审——在恰好可得的情况下，是一种意义相当强的验证形式，其信息量很可能超过"缺乏正式同行评审信号"这件事本身所暗示的悲观程度。我们建议这一类实时经济指数更明确地报告此类比较，包括负面结果，将其作为一种良好实践。
