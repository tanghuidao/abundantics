## 一、事件

2026 年 6 月初，Cloudflare 联合创始人 Matthew Prince 公布了一组数据：在 Cloudflare 网络（覆盖全球约五分之一的网站）上，自动化 agent 已占 HTTP 网页请求的 57.5%，人类占 42.5%。机器流量首次成为互联网的多数派。Prince 本人在今年 3 月的 SXSW 大会上还预测这一交叉要到 2027 年才会发生——实际比他最初的预测提前了约 18 个月。作为参照：在生成式 AI 爆发之前，机器人流量长期稳定在 20% 左右。

舆论的第一反应是复活了"死亡互联网理论"：机器成了多数，互联网正在变成机器人自说自话的舞台。

本文想说的是另一件事：**这组数据是丰裕学合并报表铁律的一次免费公开课——但前提是把它读对。它示范了一个原理，却不构成一条证据。**这两点同样重要。

## 二、换一本账，结论反转

有趣的是，Prince 本人并不认同"死网论"。他给出的理由之一是口径问题：Cloudflare 量的是 HTTP 请求——"翻网页"这个动作。如果按用户总时长计算（把看视频、用 App、刷社交都算进去），人类仍占约 65% 的网络活动。

请注意这里发生了什么：**同一个现实，换一本账，"机器成了多数派"反转为"人类仍是多数派"。**没有任何事实改变，改变的只是计数单位——请求数还是小时数。

这正是丰裕学核心命题四（多账本）的日常版本：不存在单一充分统计量能概括系统状态；任何单一口径的头条数字（"57.5%！"），其含义完全取决于账本边界划在哪里。这不是玄学，是会计学。

## 三、5 个网站与 5000 个网站：迂回度的直觉

Prince 打过一个比方：一个人买数码相机，最多逛 5 个网站就下单；但让 agent 替你办这件事，它可能访问 5000 个网站——制造出千倍于人类的流量。

用丰裕学的语言翻译：**人类最终交付没有变**（还是买到一台相机），**中间迂回活动膨胀了三个数量级**。如果有人按"总请求数"记账，会得出"网络产出爆炸增长"的结论；按"交付到人类的价值"记账，则什么都没变。

这就是合并报表铁律的直觉：当机器成为主要活动主体，把机器间（A–A）的中间活动计入总量的朴素口径，与只计跨越人机边界之最终交付的合并口径，二者之比将随 agent 中介深度（迂回度 φ）按 1/(1−φ) 张开。Cloudflare 的流量数据，可以看作这个"合并楔"在流量层的一次预演：朴素口径（全部请求）里机器占 57.5%，而合并口径关心的量——到达人类的最终交付——并未同比例膨胀。

## 四、它不说明什么

写到这里，最大的危险恰恰是顺势多说一句。所以必须逐条声明本文**不**主张什么。

**其一，流量迂回度不等于交易迂回度。**丰裕学假说 H6 中的 φ 定义在交易图上：A–A 中间**交易**占总交易额的份额，由人机交易图直接计算。Cloudflare 量的是 HTTP 请求——当前的 agent 疯狂浏览但很少付费交易，两个口径可能相差极远。把"57.5%"直接当作 H6 中 φ 上升的证据，是口径错置。**本文引用这一事件，仅作为合并楔逻辑的示意性案例（illustrative case），不作为 H6 的检验数据。**H6 的判决须等交易层数据（链上 agent 交易、可机读的 agent 身份与支付协议）积累之后，按预先注册的判据执行。

**其二，数据本身带三重限定。**（一）这是一家公司网络上的观测，覆盖约五分之一网站，不必然代表全网；（二）"bot 还是人"的分类依赖 Cloudflare 的专有分类器，Prince 本人承认数据"有点乱"、说不清具体哪天越线；（三）Cloudflare 的主营业务之一正是 bot 管理，对其报告的 bot 份额宜保持通常程度的审慎。引用这组数字时，这三条限定应随行。

**其三，本文不采纳该事件传播中的"互联网正在长成超级智能的神经网络"一类叙事。**那是修辞，不是可检验命题。丰裕学的全部赌注押在可证伪的判据上，与此类话语保持距离是纪律的一部分。

## 五、拐点已至，账本未立

如果说这个事件真正确证了什么，那就是：**智能体经济的到来速度超过了业内最乐观者的预测，而它的测量口径一片混乱**——混乱到连亲手记录拐点的人都说不清越线的日期。

在这样的时刻，缺的不是又一个宣告"时代变了"的声音，而是一套边界清晰、判据先行的账本：什么算产出、什么算中间、合并线划在哪里。这正是丰裕学把合并报表铁律列为旗舰贡献、并将其可证伪预言升格为正式假说 H6 的原因；也是 TEPI 作为活体数据基础设施逐日运行的原因。

拐点会不断出现。账本必须先立好。
