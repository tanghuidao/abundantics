## 〇、边界声明（先读这一段）

**本简报全部结果为确认性证据，不是判别性证据。** δ̂ 的 N/R 组间差无论多显著，都与丰裕学命题 1 相容、但不能判别——鲍莫尔成本病与赫希位置性商品对同一价格分化早有解释（预印本推论 1.1 已申明）。判别性回归（ProdGrowth_k + η_k + Positionality_k）需 CE 调查与产业生产率数据，尚未进入 fetch 阶段。全文「确认性 / 判别性」两词按此口径使用，不混用。

## 一、方法一句话

对 11 个已核实序列（N 类 5 个、R 类 4 个、中性 1 个、基准 1 个；大学教科书已降级排除），计算各品类**相对 CPI 总指数的年化对数价格漂移**：

> δ̂_k = [ ln(P_k(t₁)/P_k(t₀)) − ln(CPI(t₁)/CPI(t₀)) ] / T × 100 （单位：%/年）

即：δ̂ > 0 = 该品类 22 年间跑赢通胀，δ̂ < 0 = 相对变便宜（丰裕化）。分组定义的单一信息源是 `category_mapping.csv` 的「H1分组」列（v1.1 起脚本不再维护分组常量）。

| 组 | 定义 | 成员 |
|---|---|---|
| **N**（难自动化·照护·位置性） | 稀缺向之迁移 | 医院服务、大学学费、医疗护理服务、托儿照护、住房（OER） |
| **R**（可复制·可贸易） | 丰裕化下跌 | 手机通信服务、电脑软件、玩具、电视机 |

## 二、核心检验：N/R 组间差（2000-01 → 2021-12，T=22）

与预印本附图 1 同口径窗口（β=1.98 脚注），但用自动化实际口径：无教科书 + 住房 OER。

**逐品类 δ̂（%/年，相对 CPI）：**

| N 组 | δ̂ | | R 组 | δ̂ |
|---|---:|---|---|---:|
| 医院服务 | +3.088 | | 手机通信服务 | −4.624 |
| 大学学费 | +2.316 | | 电脑软件 | −7.874 |
| 医疗护理服务 | +1.353 | | 玩具 | −8.201 |
| 托儿照护 | +1.114 | | 电视机 | −18.772 |
| 住房（OER） | +0.357 | | | |
| **均值** | **+1.645** | | **均值** | **−9.868** |

**组间差与检验：**

| 指标 | 值 |
|---|---|
| β(N−R) | **+11.513 个百分点/年** |
| 累计（×22 年） | **+253.3%（对数 2.533）** |
| Welch t / df / p | 3.699 / 3.14 / 0.0317 |
| Mann-Whitney U（精确双侧） | U=20（完全分离），p=0.0159 |

**与预印本手工统计的对照**（情况A：预印本原口径，含教科书、住房整体口径）：

| 口径 | β（22 年对数） | Welch t / p |
|---|---|---|
| 预印本手工（脚注原文） | 1.98 | 2.74 / 0.050 |
| 自动化流水线复现（情况A） | 1.98 | 2.737 / 0.0499 |
| 自动化实际口径（本简报，情况B） | 2.533 | 3.699 / 0.0317 |

自动化流水线**逐位复现了预印本手工结果，且在更严格的品类口径（无教科书、OER）下信号更强**。非参数交叉验证（Mann-Whitney 精确检验，穷举 C(9,5)=126）与 Welch 方向一致且更显著，说明结论对分布假设不敏感。

**结论措辞（按 caveat 降级要求）**：在当前 11 个试点品类（含 1 对嵌套子项）上，方向性证据强于预印本原始手工统计；但样本量小、且医院服务与医疗护理服务非完全独立，真正有推断力的检验有待品类映射表扩展至 CPI 全样本后进行。**不写「组间差异统计显著（p=0.032）」一类定论式表述。**

## 三、样本外验证（2022-01 → 2026-07，T=4.5，与核心窗口零重叠）

这段数据在预印本成稿时**根本不存在**——这是第一次能对预印本做真正的样本外检验（不同于跨窗口稳定性 r=0.998 的 18 年重叠，那是同一段历史算两遍）。

**逐品类 δ̂（%/年，相对 CPI）：**

| N 组 | δ̂ | | R 组 | δ̂ |
|---|---:|---|---|---:|
| 住房（OER） | +1.258 | | 手机通信服务 | −5.310 |
| 医院服务 | +0.908 | | 玩具 | −3.987 |
| 托儿照护 | +0.847 | | 电脑软件 | −1.362 |
| 医疗护理服务 | −1.299 | | 电视机 | −11.645 |
| 大学学费 | −1.922 | | | |
| **均值** | **−0.042** | | **均值** | **−5.576** |

| 指标 | 核心窗口（22 年） | 样本外（4.5 年） |
|---|---:|---:|
| β(N−R) | +11.513 个百分点/年 | **+5.535 个百分点/年** |
| 累计 | +253.3% | +24.9% |
| Welch t / p | 3.699 / 0.0317 | 2.429 / **0.0804** |
| Mann-Whitney 精确 p | 0.0159 | 0.0317 |

**解读**：

1. **方向成立**——样本外 N 仍系统性高于 R 约 5.5 个百分点/年，全部 4 个 R 品类继续相对下跌，N/R 排序近乎完全分离（U=19/20）。
2. **量级减半**——β 从 11.5 降至 5.5 个百分点/年；4.5 年窗口短、且 2022–2023 高通胀期对端点敏感，量级本身的参考价值有限，方向与秩次才是重点。两个已知压低因素：电脑软件 2024 后真实反转（抬 R 组均值约 1–2 个百分点/年，见六）；医疗护理的健康保险核算故障压低 N 组均值约 0.2 个百分点/年（见下文排查）。
3. **检验强度如实在边缘**——t 检验 p=0.08（边际），Mann-Whitney 精确 p=0.032 仍给出方向性支持。简报如实呈现，不做修饰。
4. **N 组内部结构变化值得注意——两项转负已逐项排查，性质完全不同**：样本外领跑的是住房 OER(+1.26)、医院(+0.91)、托儿(+0.85)；学费(−1.92)与医疗护理(−1.30) 转负。22 年窗口中的排序（医院>学费>医疗>托儿>住房）在样本外**并未原样延续**。

**转负项排查（2026-09-02 补做，复现代码 `h1_hi_diagnostic.py`）**：

- **医疗护理服务（−1.30）＝已排查为 BLS 健康保险 CPI 核算故障所致，非稀缺迁移方向逆转。** SAM2 内含健康保险子项（SEME，占其权重约 11%），其「留存收益法」（保费减理赔的会计残差代理价格）在疫情期间失灵：指数 2022-09 冲上峰值（同比一度 +28.2%），随后核算修正引发崩塌（2023-07 同比 −29.5%），BLS 于 2023-10 依国家院 CNSTAT 建议改为半年更新 + 两年移动平均。崩塌横跨整个样本外窗口：SEME 相对漂移 **−9.88%/年**，对 SAM2 的拖累约 **−1.05~−1.11 个百分点/年**（Laspeyres 分解，官方权重与拟合权重两法一致，路径拟合 R²≈0.99~0.998）。**排除健康保险后，ex-HI 口径的医疗护理服务相对漂移仅约 −0.2 ~ −0.35%/年**（官方权重 −0.20、拟合权重 −0.35；医院及相关 +1.07、专业服务 −1.17 的混合）——基本走平，−1.30 中的绝大部分是统计事故的消退，不是价格结构信号。对核心窗口的污染经核查可忽略：故障峰值在 2022-09 之后，健康保险 2021 全年仅 −1.0%，摊到 22 年核心窗口约 −0.005 个百分点/年。
- **大学学费（−1.92）＝真实市场现象，非统计假象。** NACUBO 调查显示私立非营利高校学费折扣率连创历史新高（首年新生折扣率 2022-23 学年 54.8% → 2023-24 学年 56.1%），实际净学费收入连年跑输通胀；College Board 同期记录名义学费涨幅处于历史最低区间、实际下跌，叠加 18–24 岁人口池收缩与入学人数下滑。这与「招生市场竞争约束学费定价」一致——N 类内部异质性（学费放缓 vs 医院坚挺）本身是 η 随时间变化的候选观察，与第五节「排序取决于 η−ε」的解读相容，留待判别性设计检验。

**样本外窗口 caveat**：医院 2 个源侧缺月（2022-10、2024-08）与 2025-10 停发占位月均落在窗口内部，不影响端点法 δ̂（两端点均存在）。医疗护理服务含已知核算故障子项（健康保险）：**核心窗口（2000–2021）基本不受影响**（污染约 −0.005 个百分点/年），**样本外窗口受影响明显**（已按上文分解量化）；引用样本外医疗护理 δ̂ 时应优先使用 ex-HI 口径的定性结论。本窗口仍属确认性证据。

## 五、组内排序：η−ε 异质性的初步线索

**N 组排序**：医院(+3.09) > 学费(+2.32) > 医疗(+1.35) > 托儿(+1.11) > 住房OER(+0.36)
**R 组排序**：手机(−4.62) > 软件(−7.87) > 玩具(−8.20) > 电视(−18.77)

这个排序不只是描述性花絮——它本身是对「**漂移速度取决于 η−ε（需求收入弹性减供给生产率弹性），而不是一个模糊的类别标签**」这一理论主张的初步支持：同为 N 类，医疗需求的收入弹性远高于位置性住房，医院 δ̂（+3.09）就远快于住房 OER（+0.36）；同为 R 类，电视的摩尔定律式生产率进步远快于通信服务，跌幅也深得多。若丰裕学机制成立，后续判别性回归应能把这条排序追到品类级的 η、ε 数据上，而不是停留在「N/R」二分。

## 六、电脑软件 2024 后反转（单独说明）

- 2000→2024 累计 −73.3%，2000→2026 回到 −67.3%：**2024-07 后软件价格真实上涨约 22%**。
- 最新同比（2026-07 vs 2025-07）**+21.2%**，近 2 年年化漂移已转正（+7.13%/年）。
- 复核确认：真实反转、非映射错误、非口径假象（红线结论）。具体诱因（定价模式变化 / AI 成本结构 / 关税传导）留待品类扩展后追因；在样本外窗口中它已把 R 组均值抬高约 1–2 个百分点/年，是 β 减半的贡献因素之一。
